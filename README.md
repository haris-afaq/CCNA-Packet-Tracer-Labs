# CCNA Packet Tracer Labs

A collection of practical Cisco Packet Tracer labs covering
networking concepts and CCNA certification topics.

## Topics

- Network Fundamentals
- IP Addressing and Subnetting
- VLANs and Trunking
- Static Routing
- Dynamic Routing (RIP, OSPF, EIGRP)
- DHCP and DNS
- Access Control Lists (ACL)
- WAN and Serial Connections

## Tools

- Cisco Packet Tracer
- Cisco IOS CLI
